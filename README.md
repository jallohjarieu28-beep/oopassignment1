# Digital Learning Portal — Student Management System

A Python-based Object-Oriented Programming (OOP) project that demonstrates core software engineering principles through a Digital Learning Portal student management system.

---

## 📌 Features

* **Student Object Management:** Instantiates and manages individual student profiles with attributes including `student_id`, `name`, `age`, and `major`.
* **Course Enrollment:** Handles immutable course details (e.g., `PROG211 - Object-Oriented Programming 1`) stored in tuples.
* **Class Attributes:** Tracks the total number of active students currently registered across the system using class-level counters.
* **Record Updates:** Provides instance methods to update student information dynamically.
* **Portal Operations:** Allows adding student instances and displaying formatted records for system-wide auditing.
